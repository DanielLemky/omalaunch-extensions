Claude Code for Omalaunch

Launch a new Claude Code session directly from Omalaunch.

Installation

omarchy plugin add https://github.com/DanielLemky/omalaunch-claude --enable

Usage

Open Omalaunch and type:

claude your prompt here

Typing part of claude shows Claude Code as a result. Press Enter to complete the prefix, type a prompt, then press Enter again to launch Claude Code in a terminal.

Requirements

  • Omalaunch
  • Claude Code CLI (claude)

This extension does not install dependencies automatically.

Removal

omarchy plugin remove omalaunch.claude
