Pi for Omalaunch

Launch a new Pi session directly from Omalaunch.

Installation

omarchy plugin add https://github.com/DanielLemky/omalaunch-pi --enable

Usage

Open Omalaunch and type:

pi your prompt here

Typing pi shows Pi Agent as a result. Press Enter to complete the prefix, type a prompt, then press Enter again to launch Pi in a terminal.

Requirements

  • Omalaunch
  • Pi CLI (pi)

This extension does not install dependencies automatically.

Removal

omarchy plugin remove omalaunch.pi
